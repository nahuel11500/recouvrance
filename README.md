# Media

Screenshots and the tour GIF shown in the main README. They live on this branch so `main` stays
small. All of them were taken with the developer snapshots (`--features dev`, see
`docs/development.md` on `main`) on a throwaway kind cluster (`kind-demo`) running a demo shop
with a few deliberately broken workloads, never on a real cluster.

The website (nahuelcanavy.com/recouvrance) keeps its own WebP copies of the same images.
